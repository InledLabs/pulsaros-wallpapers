## 🚀 Instalación manual

Si deseas instalar los fondos manualmente en tu sistema Pulsar OS / Linux:

```bash
git clone https://github.com/InledLabs/pulsaros-wallpapers.git
cd pulsaros-wallpapers
bash install.sh
```

Los fondos se instalarán en `/usr/share/backgrounds/macos/` y estarán disponibles inmediatamente en los Ajustes de GNOME (Fondo de pantalla).
